# TaskFlow

TaskFlow is a self-hosted project management platform for planning, organizing, tracking, and collaborating on work from one place.

## Features

- Work items and task tracking
- Cycles and sprint planning
- Modules and project organization
- Custom views and filters
- Pages and team documentation
- Analytics and progress tracking
- Team collaboration
- Self-hosted deployment

## Deployment

TaskFlow can be deployed with Docker / Docker Compose and adapted for production infrastructure as required.

## Local development

See [CONTRIBUTING.md](./CONTRIBUTING.md) for development setup and contribution guidance.

## Technology

The application uses technologies including:

- React / React Router
- Django
- Node.js
- PostgreSQL
- Valkey / Redis-compatible services
- RabbitMQ
- S3-compatible object storage
